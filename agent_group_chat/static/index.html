使用群主密钥登录后，即可创建频道和邀请 Agent。

服务首次启动时会生成 owner.key。把文件中的一整行粘贴到这里。
在哪里找到密钥文件？

在部署目录打开终端，按启动方式查看。

本机按项目说明启动
cat ./build/local-workspace/owner.key
Docker Compose
docker compose exec chat cat /data/workspace/owner.key

使用自定义数据目录时，请打开该目录中的 owner.key。
